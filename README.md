# LinkFlow

**LinkFlow** connects an Android phone and a Windows PC, bringing useful
phone features and controls together in one companion app.

> Project status: Some features are working, while USB connectivity and
> audio-routing features are still under development. Feature
> availability may vary by build.

## Features

-   **Device pairing** --- Connect an Android phone and Windows PC using
    a simple pairing flow with a 4-digit PIN.
-   **Automatic reconnection** --- Reconnect to a previously paired
    device when it is available nearby.
-   **Clipboard sync** --- Synchronize clipboard content between the
    phone and PC.
-   **File sharing** --- Transfer files between Android and Windows.
-   **Camera sharing** --- Use the phone's camera on the Windows PC.
-   **Screen sharing** --- Share the phone screen with the PC, view the
    PC screen on the phone, and use the phone as a second screen.
-   **Controller** --- Use the phone as a controller for games and other
    PC interactions. Controller layouts are customizable, with
    Xbox-style and PlayStation 5-style layout options and phone
    vibration feedback.
-   **AutoType** --- Type text on the Windows PC from the phone.
-   **Trackpad** --- Use the phone as a wireless trackpad for the PC.
-   **USB connection** --- USB/ADB connection support is under
    development, with the goal of supporting LinkFlow features over USB
    as well as Wi-Fi.
-   **Audio and microphone** --- Phone-as-speaker, phone-as-microphone,
    and PC-audio-to-phone capabilities are under development.
-   **Appearance customization** --- Customize Light Mode with a colour
    wheel and save up to three presets. Dark Mode uses a fixed theme.

## Supported platforms

-   **Windows:** Windows 10 and Windows 11
-   **Mobile:** Android (newer versions)

## Website

The LinkFlow website is a separate product and download-information
page. It includes an overview of LinkFlow features, a walkthrough of the
connection process, an interactive 4-digit PIN pairing demonstration,
and download links for Windows and Android.

## Project status

LinkFlow is under active development. Pairing, automatic reconnection,
Wi-Fi connectivity, file sharing, clipboard synchronization, phone
camera access, and screen sharing have been reported as working in the
current development build. USB connectivity and audio-routing features
remain under development. Controller and AutoType are included as
LinkFlow features; their availability depends on the current app build.

## Contributing

Contributions, bug reports, and suggestions are welcome. When changing
the app, take care not to break existing working features or
compatibility between the Android and Windows components.
